## 如何使用“笔记”功能

当在投影圣经中点击“加入笔记”时，选定的经文将被添加到笔记列表。
在笔记列表中，您可以：

-   编辑笔记内容（支持为笔记重新定位经文范围）
-   调整记录顺序（上移/下移）
-   删除记录

## 笔记显示模式

在“其他 - 笔记显示模式”中可切换以下模式：

-   范围
-   范围和笔记
-   经文和笔记
-   打印

当选择“打印”模式时，笔记页会显示“打印”按钮，可直接进入浏览器打印流程。

## 文件操作

笔记完成后，您可以：

-   使用“下载”将笔记 JSON 导出到本地
-   使用“打开”加载已有笔记文件
-   使用“保存”覆盖当前已打开文件
